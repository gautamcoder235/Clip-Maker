# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of **Clip Maker**.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of Clip Maker seriously. If you believe you have found a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please report the vulnerability confidentially:

1. **Email:** Send details to **sharmagautamkumar235@gmail.com** with the subject `[Security] Clip Maker Vulnerability Report`.
2. **Details to include:**
   - A clear description of the vulnerability and its potential impact.
   - Exact steps to reproduce or a minimal proof-of-concept (PoC).
   - Any relevant logs, environment specifications, or configurations.

### Response Timeline
- **Initial acknowledgement:** within 48 hours.
- **Status update / triage assessment:** within 7 days.
- **Fix release:** coordinated disclosure after a patch is ready.

Thank you for helping keep Clip Maker secure for all users!
