Clip Maker User Manual

Welcome to Clip Maker!

Clip Maker is a high-performance desktop application designed to crop, split, layout, overlay, and batch-render video clips for YouTube Shorts, TikTok, and Instagram Reels.

  1. Import Video: Click the Import + button in the Left Panel to import your source MP4, MOV, or WebM video assets.
  2. Live Video Viewport & Canvas: Use the interactive canvas to reposition, drag, or resize video placement and text overlay boxes in real-time.
  3. Aspect Ratio & Crop Anchor: Choose 9:16 Vertical Crop (Shorts) or 16:9 Horizontal and select crop anchors (Center, Left, Right, Top, Bottom).
  4. Live Preview Player: Click the 🎬 Live Preview button in the top toolbar to generate and view an instant real-time FFmpeg draft video in the built-in modal player!
  5. Clips Queue: Imported videos are automatically split into target duration parts in the bottom queue ready for batch export.

Layout, Backgrounds & Dynamic Overlays

Personalize your clips with custom backgrounds, headers, captions, progress marks, or facecam footage:

  • Position & Scale Controls: Adjust X, Y, Width, and Height for video placement. Use the Aspect Ratio Lock (🔗) button to toggle between proportional scaling and free un-constrained stretching.
  • Canvas & Background: Choose between a solid Background Color or click Select Background Image to overlay custom background graphics behind cropped videos.
  • Primary Text & Font Picker: Edit template text (e.g., PART {part}). Select custom system fonts using the integrated font search picker, adjust font size, letter spacing, font weight boldness, and text outline.
  • Text Presets & Cycling: Switch between Single Template or Cycle Presets mode to loop dynamic titles automatically across clips in the queue.
  • Additional Text Overlays: Add multiple independent text blocks with custom positions, colors, and font styles. Drag them anywhere on the viewport canvas!
  • Media Overlays & Chroma Key: Add image/video stickers or facecam overlays. Toggle Chroma Key settings to remove green screen backgrounds automatically.

Rendering & Batch Export

Export single clips or batch render entire queues with GPU hardware acceleration:

  • Live Preview Testing: Click Live Preview to verify layout, font styles, text overlays, and background placement before running full exports.
  • Batch Export Queue: Click Export Queue to render all clips in the queue simultaneously using multi-threaded parallel background workers.
  • GPU Acceleration: Check GPU Hardware Encoding to enable NVENC/AMF/VAAPI acceleration for up to 10x faster export rendering.
  • Render Queue Monitor: Switch to the Render Queue tab at the bottom to view real-time progress bars, completion timers, and detailed render logs.
  • Project Save & Import: Save your entire project configuration via Ctrl+S or the Save toolbar button to reload your project setup anytime!

Keyboard Shortcuts

Speed up your video creation workflow with built-in hotkeys:

Ctrl + S Save Current Project
Ctrl + O Open Existing Project
Ctrl + N Create New Project
Ctrl + Z Undo last configuration change
Ctrl + Y Redo undone change
Ctrl + B Toggle Left Sidebar
Ctrl + J Toggle Bottom Queue
Esc Close active modal or palette
H Fit video layout horizontally
V Fit video layout vertically
