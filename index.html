Clip Maker User Manual

Welcome to Clip Maker!

Clip Maker is a premium tool designed to easily crop, trim, overlay, and render video clips for platforms like Shorts, TikTok, and Reels. Here is how to get started:

  1. Import Video: Click the Import + button in the Left Panel to import your source MP4 or MOV video.
  2. Adjust Settings: In the Right Panel, choose the Aspect Ratio (e.g., 9:16 Vertical Crop for Shorts) and resolution.
  3. Set Clip Duration: In the "Encoding & Advanced Settings" section, adjust the Clip Duration (default is 50 seconds) to determine how long each output segment should be.
  4. Split Clips: When a video is imported, it automatically generates a list of clips in the Clips Queue at the bottom.

Dynamic Text & Media Overlays

Personalize your clips with headers, captions, progress marks, or custom images/videos.

  • Primary Text: Edit the template text (e.g., PART {part}). The {part} placeholder automatically increments for each rendered clip!
  • Text Presets: Manage cycling text templates to change text stylings across frames. Use the Add Preset button to register templates.
  • Additional Text Overlays: Add arbitrary overlay labels. You can place them anywhere on the preview canvas using drag-and-drop!
  • Media Overlays: Insert overlay images or green-screen (chroma) videos to superimpose templates, facecam footage, or stickers. Toggle Chroma Key and fine-tune Similarity and Blend to remove green background.

Rendering & Batch Export

Run renders in parallel with advanced GPU hardware acceleration.

  • Preview Selection: Click Preview Selection to test-play your currently selected clip with all overlays applied inside the viewer.
  • Batch Export: Specify the range of clips (e.g., from Part 1 to 5) and click Export Queue to start rendering. Renders run concurrently using the allocated background worker slots.
  • GPU Acceleration: Check GPU Hardware Encoding for NVENC/AMF/VAAPI acceleration to speed up video processing by up to 10x!
  • Track Progress: Check the Render Queue tab at the bottom to view completion status, current progress bar, and logs of active render processes.
